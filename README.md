# Court Listener Legal Research Tool

An independent, interactive legal research tool powered by the CourtListener API.

Search U.S. court cases and legal topics using everyday language, explore matching court opinions, and access case documents through direct links.

## Try the Interactive Demo

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Kbryan5393/legal-api-engineering-lab/blob/main/Court_Listener_Legal_Research_Tool.ipynb)

1. Click **Open in Colab**.
2. Scroll to the bottom of the notebook.
3. Click the **Play** button beside the legal research dashboard code.
4. Enter a case name or legal topic.
5. Click **Search CourtListener** and allow a few seconds for results.

## Features

- Plain-language case and legal topic searches
- Live CourtListener API integration
- Court names, filing dates, and clickable case links
- Interactive legal research dashboard
- Python, Pandas, SQL, and automated API testing examples
